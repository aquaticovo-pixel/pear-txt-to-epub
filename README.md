# Pear TXT → EPUB

A tiny iPhone-friendly, browser-local TXT → EPUB converter for Kindle.

- Processes TXT locally in the browser
- Does not upload book content
- Uses `zh-CN`
- Does not embed fonts
- Does not set `font-family`
- Does not lock font size, line height, or weight
- Detects common chapter headings and generates a table of contents
